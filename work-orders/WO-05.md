# WO-05 Extractor and LLM wrapper

## Summary

Implemented and corrected dependency declarations, provider-boundary credential
filtering, default test discovery, and fingerprint-verified Markdown intake.
Extraction retains source URL/version/verification and the resulting spec in
local `.spec.json` sidecars. Raw PDFs and all paper artifacts remain uncommitted.

## Acceptance Criteria

Two real papers produced valid specs with nonempty ambiguities and `test_type`:

- Gao, Han, Li, Zhou, *Market Intraday Momentum*: SPY, 1min, transfer.
- de Groot, Huij, Zhou, *Another Look at Trading Costs and Short-Term Reversal
  Profits*: see `papers/de_groot_huij_zhou_reversal_2011.spec.json` for the validated
  target and explicit adaptation assumptions.

Models were chosen by the owner: Fable 5.2 if accessible, otherwise Astra for
extraction, and 6.1 Sol for workers/critics. Anthropic model listing, Fable and
Opus requests returned 401 `invalid x-api-key`; the rc key matched the inherited
key. OpenAI verified access to `gpt-6-astra` and `gpt-6.1-sol`. Local `.env`
therefore selects the approved Astra fallback. No key values were logged.
Both SDK branches are exercised offline without changing implementation code.

The second extraction took 37.0462 s and cost an estimated $0.380705, using
24,177 input tokens (24,174 cache writes) and 1,570 output tokens. Evidence:
`runs/wo05-second-extraction.json`. The first extraction is included in WO-07's
pipeline totals. Four existing PDF/Markdown pairs were fingerprint-checked;
all raw PDFs were unchanged and all parse successfully with installed PyMuPDF.

## Out of Scope

No paper downloads, trading, metric-based optimization, or holdout access.
The Anthropic credential needs owner correction before that provider can run.
