# WO-12 — Event data and congressional strategy acceptance

## Summary

Implement availability-gated event inputs, CSV upload and catalog visibility.
Carry out the November 14 owner-sanctioned Congress acceptance run and then
the fixed committee-only version. The source approval and exact strategy rules
are recorded in AGENTS.md; no result-driven tuning is permitted.

## Acceptance Criteria

- Event Parquet files have validated UTC `available_at`, `symbol`, scalar fields
  and manifests; every write/load validates the canonical data contract.
- Optional `EXTRA` and third argument preserve legacy two-argument behavior.
  Strategies see only events known at their decision time; Eval 1 uses the same
  gate. A transaction-date trap cannot expose future disclosures.
- CSV upload is size-capped, parsed only, mapped explicitly and rejects absent
  or invalid availability timestamps. Uploaded sources remain unverified.
- Audit the approved, pinned Kadoa snapshot before use. Report retained stock
  transactions by chamber, dates, exclusions and daily-tier overlap. Stop if
  eligible coverage is under five years. Do not commit raw data.
- Freeze two described/original specs. Run the normal three variants and five
  evals for All Congress, then Committee Congress. No threshold changes.
- Report dated roster sources before use, never extrapolate their validity,
  and drop unmatched trades. Report qualifying sample count and range first.
- Every result displays source and survivorship limitations; insufficient
  committee samples display `short sample: not a verdict` and cannot be VERIFIED.
- Record each variant's status, eval count, cost-grid Sharpes, elapsed time and
  model cost alongside a non-trial SPY buy-and-hold control. Prove unchanged
  legacy results and run the relevant/full regression suites.
- The subsequent owner addition records zero-bps sensitivity and decay separately
  as gross diagnostics, with deterministic labels on failed variants. Show these
  on leaderboard and tearsheets without changing thresholds, verdicts or eval
  counts. Preserve historical evidence during diagnostic-only replay.

## Out of Scope

Threshold changes, performance tuning, live orders, new price downloads,
undated committee membership, freeform intake chat and automated source approval.
New unapproved online sources must not be downloaded or used.
