# WO-17 implementation plan

> **For agentic workers:** Use superpowers:executing-plans in this session.

**Goal:** Make stored data semantics executable and available to every agent,
then prove activity and rerun the five approved candidate papers.

**Architecture:** contract.yaml is a declarative schema and rule catalog. A
generator produces Python validator entry points, the agent data section and
DATA.md. Shared rule primitives implement those declarations; ingestion, storage
and strategy transport use the same validators and calendar derivations.

**Tech stack:** Existing Python/pandas/Arrow/exchange_calendars; YAML for the
contract and property-based tests for invariants.

**Spec:** work-orders/WO-17.md and the owner's five-step request.

## Design decisions

- Preserve minute start labels and daily New York midnight labels. Offsets refer
  to minute start, not decision time. A minute close becomes usable one minute
  after its label; target at t earns the next close-to-close interval.
- Daily session offsets represent session open (zero elapsed, session length
  remaining), with both first/last flags true. Final daily provider aggregates
  are not a point-in-time feed; extended-hours volume and revisions are explicit
  limitations. Do not claim availability at midnight or regular-session close.
- Session flags describe the calendar's first/last slot, even on truncated
  slices and missing bars. They never use the last observed row as the close.
- Generated session fields are immutable strategy inputs: reject changed values
  before accepting a strategy's output. Carry is_filled through the sandbox.
- Activity counts distinct exchange dates with nonzero target weights, including
  held exposure, not just turnover days. Zero weights or fewer than five such
  IS dates trigger INACTIVE before performance evals. Exhausted activity repairs
  retain INACTIVE; other exhausted bugs retain BUG_UNRESOLVED.
- Existing chronology and eval arithmetic remain fixed. Voiding is record-layer
  exclusion, with preserved original evidence and explicit trial eligibility.

## Review focus

- Corruption outside the requested split must invalidate the entire dataset.
- Manifest mismatch or changed bytes must not bypass validation through a cache.
- Half-day, DST and truncated-slice flags must be calendar-derived.
- Inactivity repair must never see metrics or OOS rows and must not count in DSR.
- No period or zero-volume row may silently acquire fabricated provenance.
